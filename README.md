# Simulació de Diffie-Hellman amb mètodes static (SOLUCIÓ)

Versió per al professorat: tots els mètodes d'`EinesDH` estan implementats i totes les proves passen.

## Ordres útils

| Què vols fer | Ordre |
| --- | --- |
| Executar les proves | `mvn test` |
| Executar el programa | `mvn compile exec:java` |
| Generar la documentació (Javadoc) | `mvn javadoc:javadoc` (es crea a `target/reports/apidocs/index.html`) |

Requisits: Java 17 o posterior i Maven 3.6 o posterior.
